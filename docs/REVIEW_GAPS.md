# 复习模式的缺口

对照当前实现，先把自己的短板说清楚。等调研结果回来后再补充多邻国的做法。

## 现在有什么

| 能力 | 实现 |
|---|---|
| 卡片来源 | 翻译过的句子，按 corrected 去重 |
| 调度 | Leitner 五档：1 / 3 / 7 / 15 / 30 天 |
| 判分 | 自动：相似度 ≥60 记得，≥35 模糊，否则忘了 |
| 题型 | 每次一道，由 AI 按错点类型生成（RECALL / CLOZE / FIX_ERROR / MEANING） |
| 入口 | 只有一个「开始练习」 |
| 结束 | 做完队列即结束 |

## 缺口

### 1. 只有一种练习，没有分工

现在「复习」和「练习」是同一件事：把到期卡片过一遍。

但实际上有三种不同的需求：

- **巩固已学的**（到期复习）——现在的功能
- **练错过的**（错题重练）——现在混在到期卡片里，没有独立入口
- **学新的**（生成新句子）——现在藏在右上角一个链接里

### 2. 会话没有结构

- 长度固定为「所有到期卡片」，可能是 2 张也可能是 40 张
- 没有开场、没有收尾
- 答错的卡片本次会话不会再出现，要等到明天
- 没有难度递增或穿插

### 3. 错题没有单独追踪

错题只体现在 `lapses` 计数上，没有「这个词我错了三次」这样的记忆。一个错过的句子和其他到期句子完全平等。

### 4. 间隔是死的

1/3/7/15/30 是固定表。实际上：

- 简单句和难句用同样的间隔
- 答错一次直接归零，惩罚过重
- 没有「这张卡片我从来没错过，可以拉长」的机制

### 5. 会话结束得很突然

做完最后一张，直接跳到庆祝页。没有回顾、没有「今天你攻克了这几个点」。

### 6. 没有主动回忆之外的强化

只有做题。没有：
- 看一遍今天的错误总结
- 听一遍今天练过的句子
- 把同一语法点的多个句子放一起对比

### 7. 复习和真实使用是断开的

App 的核心是输入法，但复习只在 App 里发生。写作时不会提示「这个用法你上次错过」。
