你是资深矢量插画设计师，请为「译键」这款中英互译输入法 App 设计吉祥物，并输出可直接使用的 SVG 代码。

## 角色设定

名字叫「咕咕」，是一只信鸽。选择信鸽的理由：这个 App 做的事是把一段意思从中文送到英文，或从英文送到中文——正是信鸽几千年来做的事。

它的性格：话痨、热心、从不居高临下地纠正你。像个脾气很好的英语老师。

## 必须遵守的硬性约束

### 1. 尺寸要求
- viewBox 使用 `0 0 64 64`
- **必须在 48px 下仍能一眼认出是鸟**，这是第一优先级，其他都要为它让路
- 不要用只有大尺寸才看得见的细节（羽毛纹路、渐变、阴影、高光边）

### 2. 造型要求
- 只允许 4 到 6 个形状，超过就很难在 48px 下保持清晰
- 必须有明确的**头身分界**：头比身体窄，中间有收窄的脖子转折。这一条最关键——没有它就是一颗蛋
- 必须有**外翘的尾羽**：从身体两侧偏后伸出。这是鸟和圆形卡通角色最强的区分点
- 眼睛必须是**竖椭圆并带一个白色高光点**。纯圆点会显得呆滞
- 纯色填充，不要描边，不要渐变，不要阴影

### 3. 配色（必须精确使用这些值）
- 身体主色：`#8AA4C8`（雾蓝灰）
- 翅膀/亮部：`#9DB5D4`
- 尾羽/暗部：`#7A93B8`
- 喙与脚：`#FF9600`（橙色，全身唯一暖色）
- 眼睛：`#1C2B43`
- 眼睛高光：`#FFFFFF`，透明度 0.85

不要使用纯灰（`#999999` 之类），它会和界面里的禁用态混淆。

### 4. 技术规范
- 纯净的 SVG，不要外层 HTML
- 不要 `<style>` 标签，所有颜色写在属性上
- 不要 filter、mask、clipPath（渲染器兼容性）
- 每个图形加简短注释说明是什么
- SVG 标签内可选：`<title>信鸽咕咕</title>`

## 需要输出的内容

请输出三个版本的 SVG：

### 版本 A：正面站立（主形象）
- 正视角度，翅膀收拢
- 圆头、水滴形身体、外翘尾羽、橙色喙和两条短脚
- 眼睛是竖椭圆 + 左上角高光
- 表情平静友善

### 版本 B：开心（庆祝用）
- 与 A 相同的身体
- 眼睛变成向上弯的弧线 `^ ^`（表达笑意）
- 翅膀向外张开上扬

### 版本 C：侧脸（用于 App 图标）
- 侧视角度，只露出一只眼睛
- 简化到极致：头 + 喙 + 一只眼睛 + 一点胸部轮廓
- 侧脸更适合小尺寸图标，因为正脸的两只眼睛会挤成一团

## 输出格式

先输出版本 A 的完整 SVG 代码，然后 B，然后 C。每个 SVG 后面用一句话说明设计意图。

最后再补充一段：如果要在 48px 下进一步简化，你会删掉哪些元素、保留哪些。
